# Approved commission publication requirements

Requirements and behavior below are accepted. No design or implementation is
requested. Rates are percentage values; dates are calendar dates.

- R1: A reviewer may propose a rate for one treaty section within their organization.
  A user in another organization may neither read the proposal nor change it.
- R2: A rate is required and is valid from 0 through 100 inclusive. Unknown or
  invalid rates cannot be submitted for approval. Unknown is distinct from 0.
- R3: Publication requires an approver and evidence from a signed document version
  with an existing source page/span reference. A draft or a missing reference
  cannot support publication. Reviewer access alone does not permit publishing.
- R4: A proposal never changes the published value before approval. A published
  change affects only the named section on dates from the start inclusive to the
  optional end exclusive. An end must be later than the start. Outside the
  interval, the earlier published value applies. An omitted end has no end date.
- R5: Repeating publication of an already published proposal returns the existing
  publication and does not create another approval or historical record. If the
  section's published decision has changed since the proposal was reviewed,
  publication is refused until it has been reviewed against the new decision.
- R6: Disagreeing candidates with overlapping intervals require an explicit
  approver resolution retaining the alternatives, decision and source evidence.
  Upload order does not resolve the conflict. Earlier decisions remain auditable.

## Representative business example

Treaty T-42 has property section S-P at 12.5% and casualty section S-C at 10%.
A signed addendum proposes 13% for S-P from 2026-11-01 through 2026-12-01 exclusive.
User Riley is a reviewer, Alex is an approver, both in organization Org-A.
User Morgan belongs to Org-B. Evidence is document version D-7-v2, page P-3,
span SP-18. Unsigned revision D-7-v3 proposes 14%. Two signed candidates may also
disagree; no implicit precedence rule beyond R6 has been accepted.
